## Design and implementation

The portfolio is built with **HTML, CSS, and vanilla JavaScript**, and hosted on **GitHub Pages**. It uses a lightweight static architecture with no framework or build step.

- English and French content with a persistent language preference.
- Dedicated mobile layouts alongside tablet and desktop styling.
- A dark theme, restrained motion, and reduced-motion support.
- Semantic HTML, keyboard navigation, visible focus states, and a skip link.
- Localized page metadata and descriptive image text.
- Centralized project and certification records.

Typography uses Manrope and DM Mono through Google Fonts, with system-font fallbacks. Official NVIDIA course titles retain their English wording in both language versions.

## Explore locally

Python 3 can serve the site without installing project dependencies:

```sh
git clone https://github.com/Firas443/Portfolio.git
cd Portfolio
python -m http.server 4173
```

Then open [localhost:4173](http://localhost:4173/). Any static web server can also serve the repository root.
